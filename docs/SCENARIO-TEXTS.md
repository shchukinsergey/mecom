# Оформление новостей сценариев

Эти правила обязательны при добавлении и редактировании сценариев. Новости пишутся
вручную для каждого периода, а не разбиваются по количеству символов.

## Структура

1. Сначала сюжет: один смысловой фрагмент на абзац, обычно 1–3 предложения.
   Разделяйте событие, цитату и последствия, когда это улучшает чтение.
2. В первом игровом периоде вынесите явно заданные численные условия в блок
   «Условия периода». В последующих периодах — в «Что меняется».
3. После заголовка каждая строка списка начинается с `• `.
   Между сюжетными абзацами и блоком условий оставляйте пустую строку.
4. Если в источнике нет явных изменений параметров, оставьте только сюжет.
   Не добавляйте советы по решениям, прогнозы и скрытые правила движка.
5. Не дублируйте внутри текста название сценария и номер периода:
   их добавляет канал отображения. Не используйте DOS-шапки из тильд и
   жёсткие переносы строк по ширине старого экрана.

## Точность и типографика

- Сохраняйте события, цитаты, сроки, числа, ставки и экономический смысл.
  Допускаются исправления опечаток и пунктуации без смены смысла.
- Числа: `15 000 $`, `20%`, диапазон `10–200 $`.
- Не выводите из текста новые условия: если в исходнике нет экстренного кредита,
  не добавляйте его из предположений. Различайте дополнительный кредит и общий лимит.
- Сохраняйте сюжетные проценты и сроки в сюжете. Не превращайте их в настройки игры.
- Противоречие текста и численных параметров требует отдельного решения:
  форматирование не должно незаметно менять ни текстовый смысл, ни расчётные данные.

## Хранение и совместимость

Новые сценарии сразу содержат оформленный `news`: абзацы через `\n\n`,
список через `\n` с маркерами `• `. Материализация плана сохраняет этот текст
в `scenarioNewsText`; численные поля остаются отдельными и не извлекаются из прозы.

Для исторических сценариев исходные JSON, контрольные суммы и сохранения остаются
неизменными. Ручные редакции находятся в `src/report/scenarioEditorial.json`:
8 текстов «Тракторы», 9 «iPad», 8 «Е-мобиль». `scenarioNews.ts` применяет редакцию
только при совпадении полного нормализованного исходного текста. Пользовательские
правки не подменяются редакцией по одному лишь номеру периода.

## Отображение и проверка

- Кабинет игрока: абзацы, заголовок условий и семантический список.
- Telegram: экранированный HTML, жирный заголовок и строки списка;
  учитывайте лимит Telegram и не публикуйте будущие периоды.
- Моноширинный отчёт: тот же текст, перенос строк в пределах ширины отчёта.
- Нулевой период — инициализация без своей новости; отчёт периода 0 показывает
  условия первого игрового периода с явным номером 1.
- Тестируйте все периоды и версии, сохранение чисел, отсутствие пропусков,
  пользовательские тексты и отсутствие раскрытия будущих событий.
- Для изменений запускайте `npm test`, `npm run typecheck`, `npm run build`.
