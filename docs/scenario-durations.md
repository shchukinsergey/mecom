# Длительность оригинальных сценариев

Проверено по расшифрованным оригиналам MECOM 2.07:

| Сценарий | Игровых периодов | Первое сообщение о завершении |
| --- | ---: | --- |
| Тракторы (`tractory.SN2`) | 8 | «ПЕРИОД №8 БЫЛ ПОСЛЕДНИМ!» в слоте 8 |
| iPad (`ipad.SN2`) | 9 | «9 ПЕРИОД БЫЛ ПОСЛЕДНИМ!» в слоте 9 |
| Е-мобиль (`emobile.SN2`) | 8 | «8 ПЕРИОД БЫЛ ПОСЛЕДНИМ!» в слоте 8 |

Нумерация слотов начинается с нуля: слот 0 относится к игровому периоду 1.
Начальный отчёт периода 0 не входит в длительность игры. В каждом файле есть
16 числовых записей, включая записи после завершения; их заполненность не
определяет длительность. Поздние сообщения содержат остатки общего шаблона.

Новые игры используют версии v3: iPad содержит девятый период с оригинальными
48 параметрами и новостями. Окончание игры определяется сохранённым
`scenario.playablePeriods`. Сохранённые v1/v2 остаются восьмипериодными,
их планы не мигрируются. Обычная игра по-прежнему длится 8 периодов.

Повторная проверка исходников: `python scripts/verify-scenario-durations.py PATH`.
Скрипт сверяет SHA-256, все глобальные параметры, игровые записи и новости.
