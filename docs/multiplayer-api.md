# Онлайн-режим MECOM V2: только локальный сервер

**Статус:** V2 обслуживает только локальные подключения. Интерфейс: `127.0.0.1:5174`; API: `127.0.0.1:8790`. Публичные туннели и удалённый доступ не используются и не настраиваются.

## Быстрый запуск

1. Из корня `mecom-v2` запустите `npm run online:share`. Скрипт создаст случайный токен ведущего, соберёт клиент и запустит локальный сервер.
2. Откройте локальную страницу ведущего по адресу, показанному скриптом. Если список лиг пуст, импортируйте файл лиги в V2: browser `localStorage` основной версии из другого порта не переносится.
3. Создайте партию и подключайте участников только на этом компьютере. Для удалённых игроков эта версия не доступна.
4. Начните игру при наличии минимум двух фирм. После сдачи решений рассчитайте период; для повторного входа используйте персональную ссылку.

Игры V2 хранятся отдельно в `data/server-state-v2.json`. Создавайте резервную копию файла при остановленном сервере. В нём игровые данные и хеши секретов; не публикуйте и не отправляйте его. Если API-порт `8790` занят, запуск прекращается — скрипт не переключится на другой порт.

## Права доступа и риски

- Администраторский bearer-токен нужен для управления игрой и никогда не задаётся в исходном коде.
- Игрок видит своё решение и свои частные отчёты. Статусный экран показывает названия фирм и отметки сдачи, но не значения решений или финансовые результаты соперников.
- Ссылка приглашения — bearer-секрет: всякий, кто её получил, может создать фирму, пока лобби открыто. Лимит — 12 фирм; после старта приём новых фирм закрыт. При утечке до старта замените приглашение.
- Ссылка повторного входа даёт доступ к одной фирме. Передавайте её только её участнику; при перевыпуске прежний токен перестаёт работать.
- Скрипт V2 намеренно не обнаруживает и не запускает Cloudflare или другой туннель.

## API

Все маршруты находятся под `/api`. Административные запросы используют `Authorization: Bearer …`, игроки — `X-MECOM-PLAYER`, создание фирмы — `X-MECOM-INVITE`.

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/health` | Проверка сервера |
| `POST` | `/api/games` | Создать игру из снимка лиги (админ) |
| `POST` | `/api/join` | Создать фирму по приглашению |
| `GET` | `/api/admin/games/:id` | Получить игру ведущему |
| `POST` | `/api/admin/games/:id/invite-token` | Заменить приглашение в открытом лобби |
| `POST` | `/api/admin/games/:id/firms/:firmId/rejoin-token` | Выпустить новую ссылку входа фирме |
| `POST` | `/api/games/:id/start` | Начать игру (минимум две фирмы) |
| `PUT` | `/api/admin/games/:id/macro` | Изменить параметры периода |
| `POST` | `/api/admin/games/:id/calculate` | Рассчитать период после сдачи всеми фирмами |
| `POST` | `/api/games/:id/close` | Закрыть игру |
| `GET` | `/api/player/me` | Данные своей фирмы и её отчёты |
| `PUT` | `/api/player/decision` | Сохранить решение своей фирмы |
| `POST` | `/api/player/submit` | Сдать решение |
| `GET` | `/api/games/:id/status` | Названия фирм и статусы сдачи |
| `GET` / `PUT` | `/api/state` | Снимки лиг администратора; замена снимка не удаляет онлайн-игры |

Подробности модели и формул см. в `DOCS.md` и `mecom-spec.md`.
