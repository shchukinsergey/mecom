# Онлайн-режим MECOM: локальный сервер и публичный доступ

**Статус:** онлайн-интерфейсы ведущего и игрока, API, расчёт через существующий движок, статическая раздача клиента и разделение доступа реализованы. Сервер остаётся привязан к `127.0.0.1`; внешний доступ создаёт отдельный Cloudflare Quick Tunnel, без открытого входящего порта на компьютере.

## Быстрый запуск

1. Сгенерируйте токен командой `node -p "require('crypto').randomBytes(32).toString('base64url')"` и сохраните вывод в менеджере паролей.
2. Из корня проекта запустите `npm run online:share`; введите сохранённый токен в скрытый запрос скрипта. При каждом перезапуске используйте тот же токен; не отправляйте его игрокам.
3. Скрипт соберёт production-клиент, запустит сервер, проверит `http://127.0.0.1:8787/health`, поднимет HTTP/2-туннель, дождётся регистрации соединения и попробует проверить публичный `/health`. Если этот компьютер не может разрешить публичный адрес, скрипт предупредит, но оставит туннель работать; проверьте адрес с отдельного устройства/сети.
4. На компьютере ведущего откройте `http://127.0.0.1:8787/#admin`, введите тот же токен и выберите лигу-шаблон. Если список лиг пуст, импортируйте файл лиги на этой же странице приложения: browser `localStorage` из другого origin/порта автоматически не переносится.
5. В поле «Публичный HTTPS-адрес сервера» укажите адрес `https://….trycloudflare.com`, показанный скриптом. Создайте онлайн-партию, скопируйте приглашение и передайте его игрокам отдельно.
6. После подключения минимум двух фирм ведущий начинает игру, при необходимости меняет макропараметры, затем рассчитывает периоды после сдачи решений всеми фирмами. Для повторного входа ведущий выпускает фирме персональную ссылку.

Игры хранятся на компьютере ведущего в `data/server-state.json`. Создавайте резервную копию этого файла при остановленном сервере. В нём игровые данные и хеши credentials; не публикуйте и не отправляйте его.

## Права доступа и риски

- Администраторский bearer-токен нужен для управления игрой и никогда не задаётся в исходном коде.
- Игрок видит своё решение и свои частные отчёты. Статусный экран показывает названия фирм и отметки сдачи, но не значения решений или финансовые результаты соперников.
- Ссылка приглашения — bearer-секрет: всякий, кто её получил, может создать фирму, пока лобби открыто. Лимит — 12 фирм; после старта приём новых фирм закрыт. При утечке до старта замените приглашение.
- Ссылка повторного входа даёт доступ к одной фирме. Передавайте её только её участнику; при перевыпуске прежний токен перестаёт работать.
- `cloudflared` соединяется с компьютера наружу и передаёт запросы через сеть Cloudflare. Cloudflare входит в сетевую границу доверия. Не используйте туннель для данных, которые нельзя передавать через этого провайдера.
- Quick Tunnel — временный режим для теста/небольшой игры: случайный адрес изменяется после перезапуска, не обещает доступность и поддерживает до 200 одновременно выполняющихся запросов. Для стабильной эксплуатации нужен именованный туннель/домен и отдельная политика доступа либо иной проверенный HTTPS-вход.

## API

Все маршруты находятся под `/api`. Административные запросы используют `Authorization: Bearer …`, игроки — `X-MECOM-PLAYER`, создание фирмы — `X-MECOM-INVITE`.

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/health` | Проверка сервера |
| `POST` | `/api/games` | Создать игру из снимка лиги (админ) |
| `POST` | `/api/join` | Создать фирму по приглашению |
| `GET` | `/api/admin/games/:id` | Получить игру ведущему |
| `POST` | `/api/admin/games/:id/invite-token` | Заменить приглашение в открытом лобби |
| `POST` | `/api/admin/games/:id/firms/:firmId/rejoin-token` | Выпустить новую ссылку входа фирме |
| `POST` | `/api/games/:id/start` | Начать игру (минимум две фирмы) |
| `PUT` | `/api/admin/games/:id/macro` | Изменить параметры периода |
| `POST` | `/api/admin/games/:id/calculate` | Рассчитать период после сдачи всеми фирмами |
| `POST` | `/api/games/:id/close` | Закрыть игру |
| `GET` | `/api/player/me` | Данные своей фирмы и её отчёты |
| `PUT` | `/api/player/decision` | Сохранить решение своей фирмы |
| `POST` | `/api/player/submit` | Сдать решение |
| `GET` | `/api/games/:id/status` | Названия фирм и статусы сдачи |
| `GET` / `PUT` | `/api/state` | Снимки лиг администратора; замена снимка не удаляет онлайн-игры |

Подробности модели и формул см. в `DOCS.md` и `mecom-spec.md`.
