# Оригинальные сценарии, версия 2

Новые игры используют tractors-v2, ipad-v2 или emobile-v2. Ранее созданные
обычные игры и сценарии v1 сохраняют прежние правила. Автоматической миграции,
пересчёта истории и замены сохранённых сценарных планов нет.

Перед работой создан архив `.local-backups/before-original-scenarios-v2.zip`:
исходники и согласованные копии имеющихся локальных SQLite-баз через backup API.
База хостинга не изменялась. Пользовательский ZIP бэкапа не перезаписывался.

## Перенос параметров

В каждой новой игре сохраняются SHA256 исходного SN2, все 128 общих значений
и все 48 числовых полей каждого из восьми используемых периодов. Значения
не запрашиваются из изменяемого каталога при загрузке сохранения.
Неиспользуемые нулевые позиции сохраняются вместе с исходными данными.

| Исходные поля ALL | Использование |
|---|---|
| 000–004 | Стоимость станка, производительность рабочего, амортизация, увольнения, оптимальная загрузка |
| 008–014 | Основной и дополнительный кредит, две ставки, комиссия, депозит, налог |
| 025–027 | Начальная мощность, хранение, начальный склад |
| 030–034 | Вводная цена, загрузка, маркетинг, дополнительные инвестиции, НИОКР |
| 036–039 | Четыре коэффициента себестоимости |
| 040–045 | Шесть вводных весов РИФ |
| 048–058 | Коэффициенты нативного спроса и показателей степеней |
| 060–066 | Вводные веса конкуренции и регуляторы спроса |
| 074–078 | Ограничения цены и трёх видов вложений |
| 080–084 | Пределы эффективности маркетинга/НИОКР, ослабление влияния, ценовая отсечка |

НДС ALL015 равен нулю во всех трёх источниках. Зарплатная доля ALL016 равна
50% во всех трёх; значение сохранено в исходных данных. В текущих отчётах
нет отдельного показателя средней зарплаты; доля не добавляется повторным
расходом поверх уже рассчитанной себестоимости. Перенос не является
универсальным импортом произвольных сторонних SN2 с ненулевым НДС.

В периодах применяются собственные кредиты, ставки, комиссия, депозит,
налог, три модификатора спроса, три веса конкуренции, штрафы, хранение,
коэффициенты себестоимости, шесть весов РИФ, ценовая отсечка и лимиты решений.
Для бюджета, серверной проверки, расчёта и планирования бота используется
единая эффективная конфигурация периода. Будущие параметры не передаются
боту через его границу наблюдения.

## Инициализация

Исходные суммы на октет масштабируются через K=ceil(N/8), распределяются
между N фирмами и округляются. Решение вводного периода берётся из общих
параметров, а не из первого игрового периода.

- Мощность: round(ALL025 × K/N).
- Выпуск: round(мощность × ALL031/100).
- Маркетинг и НИОКР: round(ALL032/034 × K/N).
- Инвестиции брутто: round(ALL033 × K/N + мощность × ALL000 × ALL002/100).
- Исходное финансирование: округлённая стоимость выпуска + маркетинг +
  НИОКР + инвестиции брутто − амортизация.
- Деньги и долг до вводного расчёта равны исходному финансированию.
- Склад: round(ALL027 × K/N); его исходная себестоимость ALL036+ALL037.
- Капитал уравновешивает стоимость фабрики и исходного товарного запаса.

При N=8 исходный склад iPad — 300 единиц на фирму. У «Е-мобиля» ценовая
отсечка 60, у остальных 40. Депозитная ставка — 8%.
Уже имеющийся до игры склад отмечается как старый для платы за хранение.

Версия 2 включает расчёт денежных итогов с округлением до целых долларов,
как в проверенных сохранениях оригинала. Остаточная стоимость склада
переносится с сохранением тождества баланса. Этот режим включён явным
флагом только в новых сценариях v2; обычные игры и v1 сохраняют прежнюю
арифметику. Это отдельный режим расчёта, не исправление прошлых результатов.

## Проверка

Получены пользовательские SHSHSHS.Z00 и соответствующие S00 для Тракторов
и Е-мобиля, по восемь фирм, период 0. Так как оригинальный файл перезаписан
вторым запуском, контрольные данные сохранены отдельными анонимизированными
fixtures со своими SHA256.

Проверенные значения совпали точно: мощность, выпуск, себестоимость,
сотрудники, проценты, заказы, продажи, склад, выручка, COGS, валовая прибыль,
прибыль до налога, налог, чистая и накопленная прибыль, деньги, НИОКР, РИФ,
капитал. В частности:

| Показатель на фирму | Тракторы | Е-мобиль |
|---|---:|---:|
| Долг | 9030 | 9030 |
| Банковские проценты | 248 | 248 |
| Прибыль до налога | 2272 | 2272 |
| Налог | 409 | 568 |
| Чистая прибыль | 1863 | 1704 |
| Наличные после периода 0 | 10893 | 10734 |

Для всех трёх v2 проверяется проход 0–8 при 2, 5, 8, 9 и 12 фирмах,
тождество баланса и JSON import/export. Серверные проверки охватывают v1
и v2, переходы периодов, сохранение/перезапуск БД и неизменность соседней
обычной комнаты. Шесть частных партий из предоставленного бэкапа сравниваются
с результатами, зафиксированными до внедрения сценариев.

Граница доказательств: точные исходные параметры и контрольные результаты
вводного периода не доказывают побитовую идентичность всех будущих ходов
оригинальному Borland float80. Для iPad и нестандартного числа фирм проверки
баланса/сохранений не заменяют независимый отчёт оригинальной игры.
